Roadmap (логика “что из чего вытекает” и как собирается)

    parse_args → values[]

    Разбираем argv, валидируем int, проверяем диапазон и дубликаты.
    Если нет аргументов (кроме имени программы) → ничего не печатаем и выходим.

    build: stack a / stack b

    Создаём stack a из values (top = первый аргумент).
    stack b пуст.

    disorder (обязательно до ходов)

    Считаем disorder по массиву values по формуле “все пары (i<j), где a[i] > a[j]”.

    ranks (индексы)

    Для стратегий medium/complex (и часто simple тоже) строим ranks: заменяем каждое значение на его позицию в отсортированном массиве (0..n-1).
    В каждом узле стека храним value и rank, чтобы сравнивать по rank.

    выбор стратегии

    --simple → simple
    --medium → medium
    --complex → complex
    --adaptive → если disorder < 0.2 simple, иначе если <0.5 medium, иначе complex

    генерация операций

    Стратегия вызывает операции op_* (sa/sb/ss/pa/pb/ra/rb/rr/rra/rrb/rrr).
    op_*:
        реально крутит/переставляет узлы в стеках
        печатает строку операции в stdout
        увеличивает счётчики операций (для --bench)

    bench (если включён)

    После успешной сортировки печатаем в stderr:
        disorder в процентах (2 знака),
        имя стратегии и её класс (O(n²)/O(n√n)/O(n log n)),
        total ops,
        count каждого типа операции.

2) Внутренняя логика стратегий (коротко, но конкретно)
strategy_simple (O(n²) через selection/min extraction)

    Пока a.size > 3:
        min_rank = stack_min_rank(&ctx->a)
        bring_rank_to_top_a(ctx, min_rank) (выбираем ra или rra по выгоде)
        op_pb(ctx) (минимум уходит в b)
    sort_three_a(ctx) (оставшиеся 3 элемента в a)
    Пока b не пуст: op_pa(ctx) (выталкиваем минимумы обратно)

strategy_medium (O(n√n) chunk/range на ranks)

    chunk_size = (int)sqrt(n) + 1
    Проходим чанки по rank:
        chunk_start..chunk_end
        пока текущий чанк не “полностью отправлен” в b:
            если top.rank <= chunk_end:
                op_pb(ctx)
                если top.rank <= chunk_start + chunk_size/2 → op_rb(ctx) (улучшает порядок в b)
            иначе → `op_ra(ctx
    После всех отправок: пока b не пуст → op_pa(ctx) (a соберётся в asc)

strategy_complex (O(n log n) radix LSD по rank)

    max_rank = get_max_rank(&ctx->a)
    maxbits = get_maxbits(max_rank)
    Для bit = 0..maxbits-1:
        for i in 0..n-1:
            если ((a.top.rank >> bit) & 1) == 0 → op_pb
            иначе → op_ra
        пока b не пуст → op_pa

strategy_adaptive

    disorder уже посчитан до ходов
    если <0.2 → strategy_simple
    если <0.5 → strategy_medium
    иначе → strategy_complex
    имя/класс стратегии сохраняем для bench_print_and_counts()
