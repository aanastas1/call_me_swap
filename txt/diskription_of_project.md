

Требуется проект *push_swap* на C (ровно 2 участника), который:
- сортирует стек **a** по возрастанию, используя только операции `sa/sb/ss/pa/pb/ra/rb/rr/rra/rrb/rrr`;
- перед любыми ходами **считает disorder** по метрике (доля инверсий `a[i] > a[j]`);
- внутри программы реализует 4 стратегии и умеет выбирать на старте флагом:
  - `--simple` → стратегия с целевой сложностью **O(n²)** в модели “по числу сгенерированных операций”;
  - `--medium` → **O(n√n)**;
  - `--complex` → **O(n log n)**;
  - `--adaptive` (дефолт) → выбирает внутренний метод по disorder:
    - disorder < 0.2 ⇒ O(n²)
    - 0.2 ≤ disorder < 0.5 ⇒ O(n√n)
    - disorder ≥ 0.5 ⇒ O(n log n)
- печатает **на stdout** только последовательность операций (каждая на новой строке), а при ошибке пишет `Error\n` в **stderr**;
- в `--bench` дополнительно на **stderr** после сортировки выводит: disorder (% с 2 знаками), имя стратегии и теоретический класс, 
общее число операций и счетчики по типам операций;
- никаких global переменных, Makefile не должен “relink”, и в README/репозитории должны быть отражены логины и вклад обоих участников.
